# Welcome to My Box!

## 概要説明
ここでは私が利便性向上のために作成しているDiscordBotのソースコードを、MITライセンスの下で公開しています。<br>
## コード説明
- CountRolesAndCalculation
    - ロールが付与されている人数を取得し、ついでに割り勘計算をするBotプログラムです。
    - 想定人数と実際の参加人数には差異が出る可能性があるため、別途、実際の参加人数確認を併用することをおすすめします。
    - ※このプログラムは作りかけです。エラーが出る可能性があります。
- SPKbot
    - このフォルダのプログラムは、/spkでｽﾋﾟｷが発する「ｽﾋﾟｷﾃﾞﾙｼﾞﾊﾞｾﾞﾖ」を、ランダムにつなぎ合わせて表示させるおふざけbotです。
    - 引数としてmodeとdakutenが設定されており、modeが1の場合は重複あり、2の場合は重複なしとなります。
        1. ex:ｳｱｱ!ｽﾋﾟｷﾃﾞｼﾞﾊﾞﾊﾞﾊﾞﾊﾞ!
        2. ex:ｳｱｱ!ｽﾋﾟｷﾊﾞｼﾞﾃﾞﾙﾖｾﾞ!
    - dakuten引数は、半角カタカナにおいて濁点が別文字として扱われる性質を利用するか否かの選択です。1は区別、2は連結です。
        - (modeが1の場合)
            1. ex:ｳｱｱ!ｽﾋﾟｷﾞﾞｾﾖｾﾞﾊｾﾞﾞ!
            2. ex:ｳｱｱ!ｽﾋﾟｷｾﾞｾﾞｼﾞｼﾞﾊﾞﾃﾞ!
