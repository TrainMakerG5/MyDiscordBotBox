# Welcome to My Box!

## 概要説明
ここは私が利便性向上のために作成をしているDiscordBotのソースコードをMITライセンスの下で公開しています。<br>
## コード説明
- CountRollsAndCalculation
    - このフォルダはロールが付与されている人数を取得し、ついでに割り勘計算をするBotプログラムです。
    - 想定人数と実際の参加人数は恐らく差異があるので、別途に実際の参加人数確認を併用することをおすすめします。
    - ※このプログラムは作りかけです。エラーが出る可能性があります。
- SPKbot
    - このフォルダのプログラムは、/spkでｽﾋﾟｷが発する「ｽﾋﾟｷﾃﾞﾙｼﾞﾊﾞｾﾞﾖ」を、ランダムに接続して表示をさせるおふざけbotです。
    - 引数としてmodeとdakutenが設定されており、mode1の場合は重複あり、2の場合は重複なしとなります。
        1. ex:ｳｱｱ!ｽﾋﾟｷﾃﾞｼﾞﾊﾞﾊﾞﾊﾞﾊﾞ!
        2. ex:ｳｱｱ!ｽﾋﾟｷﾊﾞｼﾞﾃﾞﾙﾖｾﾞ!
    - dakuden引数は半角カタカナは濁点が別文字となる性質を利用するか否かの選択です。1は区別、2は連結です。
        - (modeが1の場合)
            1. ex:ｳｱｱ!ｽﾋﾟｷﾞﾞｾﾖｾﾞﾊｾﾞﾞ!
            2. ex:ｳｱｱ!ｽﾋﾟｷｾﾞｾﾞｼﾞｼﾞﾊﾞﾃﾞ!
